Chord type

A move is one foot or one knee: pressing two pedals together counts as one move, and each knee lever counts as one.

Strings:

Each cell is the note that string goes to while that pedal or lever is engaged; the dash means no change. Changes save on this device as you make them. Two changes on the same string add together, the way an all-pull changer does.
