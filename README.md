# Chords of Steel

Find every way to play a chord on a pedal steel guitar, worked out from your own copedent. Set up any steel (strings, tuning, pedals, knee levers), and save the copedent as a PDF or text file for a tech.

## Install on a Mac

1. Open the latest release and download `Chords-of-Steel.zip`.
2. Unzip it and drag **Chords of Steel** into Applications.
3. Open it. macOS will say it can't verify the app: click **Done**.
4. Open **System Settings > Privacy & Security**, scroll down, and click **Open Anyway** next to Chords of Steel. Enter your password.

After that it opens normally.
